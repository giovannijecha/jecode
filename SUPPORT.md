# Support

For usage questions, setup help, and workflow advice, start a
[GitHub Discussion](https://github.com/giovannijecha/jecode/discussions).
Discussions keep answers discoverable without turning every question into a
tracked defect.

Open an [Issue](https://github.com/giovannijecha/jecode/issues) when you can
describe a reproducible bug or a focused product change. Use the provided form
and search for an existing report first.

Security reports do not belong in either place. Follow [SECURITY.md](SECURITY.md)
and use private vulnerability reporting from the repository Security tab.

Never post credentials, private source code, personal paths, or unredacted
conversation transcripts.
